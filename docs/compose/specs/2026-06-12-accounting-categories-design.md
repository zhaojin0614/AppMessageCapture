# 记账类别优化设计

## [S1] 问题分析

### 当前类别设置

**支出类别（7个）：**
- 餐饮
- 交通
- 购物
- 娱乐
- 生活缴费
- 医疗
- 其他

**收入类别（6个）：**
- 工资
- 退款
- 红包
- 理财收益
- 转账
- 其他收入

### 问题分析

1. **支出类别粒度不一致**
   - "餐饮"太笼统，缺少细分（早餐、午餐、晚餐、零食）
   - "购物"范围过广，包含日用品、服饰、数码等完全不同的消费场景
   - "生活缴费"涵盖水电煤、话费、物业费等差异较大的支出

2. **缺少常见支出场景**
   - 教育培训（课程、书籍、考试）
   - 人情往来（礼物、红包、请客）
   - 宠物（食品、医疗、用品）
   - 美容护肤（化妆品、理发、SPA）
   - 居家（维修、家具、清洁）

3. **收入类别不够细化**
   - "转账"含义模糊，可能是转入也可能是他人转账
   - 缺少兼职、租金、稿费等常见收入来源
   - "理财收益"可以细分为利息、股息等

## [S2] 优化方案

### 支出类别优化（12个大类）

| 大类 | 子类示例 | 说明 |
|------|----------|------|
| 餐饮美食 | 早餐、午餐、晚餐、零食饮料、外卖 | 涵盖所有饮食相关支出 |
| 交通出行 | 公共交通、打车、加油、停车、骑行 | 涵盖所有出行相关支出 |
| 购物消费 | 日用品、服饰鞋包、数码产品、家居用品 | 按消费类型细分 |
| 休闲娱乐 | 电影演出、游戏、运动健身、旅游景点 | 涵盖所有娱乐相关支出 |
| 居家生活 | 水电燃气、话费网费、物业费、房租 | 涵盖固定生活开支 |
| 医疗健康 | 门诊挂号、药品、体检、保险 | 涵盖健康相关支出 |
| 教育培训 | 课程培训、书籍文具、考试报名 | 涵盖学习成长支出 |
| 人情往来 | 礼物、红包、请客、份子钱 | 涵盖社交相关支出 |
| 美容护肤 | 化妆品、理发、SPA、健身卡 | 涵盖形象管理支出 |
| 宠物 | 宠物食品、宠物医疗、宠物用品 | 涵盖养宠支出 |
| 金融保险 | 保险费、理财投入、信用卡还款 | 涵盖金融相关支出 |
| 其他支出 | 无法归类的其他支出 | 兜底类别 |

### 收入类别优化（8个大类）

| 大类 | 子类示例 | 说明 |
|------|----------|------|
| 工资薪金 | 基本工资、奖金、补贴、加班费 | 涵盖工作相关收入 |
| 兼职副业 | 兼职收入、稿费、佣金、私活 | 涵盖副业相关收入 |
| 投资理财 | 利息、股息、基金收益、分红 | 涵盖投资相关收入 |
| 租金收入 | 房租、车位租金、设备租赁 | 涵盖租赁相关收入 |
| 退款返现 | 购物退款、优惠返现、积分兑换 | 涵盖退款相关收入 |
| 红包转账 | 微信红包、支付宝红包、他人转账 | 涵盖社交相关收入 |
| 报销补贴 | 差旅报销、餐补、交通补贴 | 涵盖公司补贴收入 |
| 其他收入 | 无法归类的其他收入 | 兜底类别 |

## [S3] 实施要点

### 数据迁移策略

1. **保留旧数据**：现有账单保持原有类别不变
2. **提供映射**：为用户提供类别映射工具，将旧类别迁移到新类别
3. **渐进过渡**：新旧类别并存一段时间，让用户逐步适应

### UI/UX 设计

1. **分类选择器**：采用网格布局，每个大类配图标
2. **子类展开**：点击大类可展开查看子类
3. **最近使用**：显示最近使用的类别，方便快速选择
4. **自定义类别**：支持用户添加自定义类别

### 技术实现

1. **数据库升级**：添加新类别表，支持二级分类
2. **兼容性处理**：确保旧版本数据正常显示
3. **性能优化**：类别数据缓存，减少数据库查询

## [S4] 预期效果

1. **用户体验提升**：更精准的分类帮助用户快速记账
2. **数据分析增强**：更细粒度的分类支持更详细的财务分析
3. **产品竞争力**：类别设置对标主流记账软件，提升产品专业性
4. **用户留存**：更科学的分类体系提高用户粘性

## [S5] 实施步骤

1. **第一阶段**：更新类别定义，添加新类别颜色和图标
2. **第二阶段**：实现二级分类选择器
3. **第三阶段**：添加类别数据迁移工具
4. **第四阶段**：优化报表和统计功能
